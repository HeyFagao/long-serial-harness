# 长篇连载工作台

DeepSeek Harness 原生插件，版本 **0.1.26-serial.3**。界面和生成提示词以原版长篇连载生成器为基础，专用于把已完成的「最终输出／超级大纲」写成小说。

- 多份最终输出一次导入，每份成为一本独立小说、一个独立工作区。
- 单本续写 10／20／50 章，或一直写至全本。
- 书库一键让所有项目新增 10／20 章，或全部写至完本。
- 原版系统提示词、单章与修订模板；每章带完整文风及前 10 章正文全文。
- 每章新建原生会话，正文与状态分开保存，进度可暂停、恢复和核对。
- 模型和多个中转站统一使用 Harness 原生设置。

安装包仅包含长篇功能，不包含剧本、游戏、视频工作台或 Oh Story 写作技能。官方宿主、模型凭据、权限和会话继续由 Harness 管理。

请先安装 [官方 DeepSeek Harness](https://deepseek.com/harness/)。已验证的宿主基线为 `0.2.2-rc.3`。下载本派生版本的预构建 `.tgz` 后，在「插件 → 添加插件」使用安装包路径或发布页提供的直链；也可执行：

```sh
dsh plugin --profile desktop add /完整路径/oh-story-dsh-0.1.26-serial.3.tgz
```

这份源码根目录是开发用 monorepo，不能作为可安装插件根。不要使用上游 npm 同名包代替本长篇版本。

## 开始使用

1. 在 Harness 新建一个空文件夹工作区，作为「小说书库」。
2. 打开长篇工作台，批量选择一个或多个最终输出 TXT／Markdown 文件。每份文件创建独立小说目录，并登记为原生工作区。
3. 在「设置 → 模型」添加中转站的基础地址、协议、密钥、准确模型 ID；在书库会话下方选定模型。
4. 点击某本书「打开」，生成 10／20／50 章或全本；也可在书库总览让所有项目各新增 10／20 章或写至完本。
5. 进度逐章保存。暂停后继续同批；共享账号／网络问题会暂停整队列，先处理错误再继续。Harness 退出后重新打开原书库并明确恢复。

运行时保持 Harness 常驻和电脑唤醒。密钥由各自电脑的 Harness 保存，安装包不含模型账号。详细使用说明、验证证据和源码位于同次交付的合伙人安装 ZIP。模拟流程测试不等于真实中转账户或文学质量验收。

派生自 [zenstory-ai/oh-story-dsh](https://github.com/zenstory-ai/oh-story-dsh) `0.1.26`（MIT），复用其原生插件接入和文件工作台基础，非上游官方发行。原生成器提示词和状态约定来自用户提供的源程序；许可证及来源说明随安装包提供。
