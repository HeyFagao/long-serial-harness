# 长篇连载工作台

DeepSeek Harness 原生插件，版本 **0.1.26-serial.6**。界面和生成提示词以原版长篇连载生成器为基础，专用于把已完成的「最终输出／超级大纲」写成小说。

- 批量勾选导出 TXT：每章一个 TXT、每本书一个 ZIP，批量下载总包；支持选择已完本、未完本导出和失败说明。
- 勾选后直接删除，无需确认或先停任务；书立即隐藏，后台停止生成并永久清理，清理暂未完成会静默自动重试。
- 多份最终输出一次导入，每份成为一本独立小说、一个独立工作区。
- 单本续写 10／20／50 章，或一直写至全本。
- 在书库先勾选，再让所选书各新增 10／20／50 章或写至完本；可明确切换到全部可新增的书。
- 暂停／继续只影响所选书，其他书照常生成；新书可加入运行中的队列，已有任务继续原目标。
- 原版系统提示词、单章与修订模板；每章带完整文风及前 10 章正文全文。
- 每章正文保存后，独立模型会话使用作者的标题提示词，只读本章；先看前 800 字抓钩子，再看前 2000 字，拟 5 个 15—25 字候选并推荐前三，自动选第一项。
- 标题候选、简短策略和番茄标签仅存内部记录；TXT 第一行为选定标题，后面是原书名、章号和正文。标题失败只重试标题，升级不改写已有正文或标题。
- 每章新建原生会话，正文与状态分开保存，进度可暂停、恢复和核对。
- 模型和多个中转站统一使用 Harness 原生设置。

安装包仅包含长篇功能，不包含剧本、游戏、视频工作台或 Oh Story 写作技能。官方宿主、模型凭据、权限和会话继续由 Harness 管理。

请先安装 [官方 DeepSeek Harness](https://deepseek.com/harness/)。已验证的宿主基线为 `0.2.2-rc.3`。下载本派生版本的预构建 `.tgz` 后，在「插件 → 添加插件」使用安装包路径或发布页提供的直链；也可执行：

```sh
dsh plugin --profile desktop add /完整路径/oh-story-dsh-0.1.26-serial.6.tgz
```

更新同一插件会保留书库、其他插件和模型设置；保存工作后重新打开 Harness。

这份源码根目录是开发用 monorepo，不能作为可安装插件根。不要使用上游 npm 同名包代替本长篇版本。

## 开始使用

1. 在 Harness 新建一个空文件夹工作区，作为「小说书库」。
2. 打开长篇工作台，批量选择一个或多个最终输出 TXT／Markdown 文件。每份文件创建独立小说目录，并登记为原生工作区。
3. 在「设置 → 模型」添加中转站的基础地址、协议、密钥、准确模型 ID；在书库会话下方选定模型。
4. 在书库勾选需要更新的书，选择每本新增 10／20／50 章或写至完本；也可打开单书生成。操作前会显示本次书籍范围与数量。
5. 进度逐章保存。勾选后可暂停或继续这些书，继续会沿用原批目标，不额外加章。全局恢复不会自动恢复单独暂停的书。共享账号／网络问题先处理，再继续；Harness 退出后重新打开原书库并明确恢复。

书库使用整页列表，选书、生成、导出与删除集中操作，不在书单里另套滚动区域。运行记录放在折叠的「查看运行记录」中，只供查看；正文、大纲及设定仍在单书项目预览和编辑。标题阶段暂停时会明确显示标题已暂停，继续只补标题。

运行时保持 Harness 常驻和电脑唤醒。密钥由各自电脑的 Harness 保存，安装包不含模型账号。详细使用说明、验证证据和源码位于同次交付的合伙人安装 ZIP。模拟流程测试不等于真实中转账户或文学质量验收。

派生自 [zenstory-ai/oh-story-dsh](https://github.com/zenstory-ai/oh-story-dsh) `0.1.26`（MIT），复用其原生插件接入和文件工作台基础，非上游官方发行。原生成器提示词和状态约定来自用户提供的源程序；许可证及来源说明随安装包提供。

书间并发默认「同时生成（不限并发）」，也可填写任意正整数，不设固定并发上限；同一本书仍逐章生成。正文验收只要求超过1500字，不设字数上限。首次失败后自动重试5次，再失败才提示处理。
