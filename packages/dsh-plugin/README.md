# 长篇连载工作台

DeepSeek Harness 原生插件，版本 **0.1.26-serial.10**。界面和生成提示词以原版长篇连载生成器为基础，专用于把已完成的「最终输出／超级大纲」写成小说。

- 批量勾选导出 TXT：每章一个 TXT、每本书一个 ZIP，批量下载总包；支持选择已完本、未完本导出和失败说明。
- 勾选后直接删除，无需确认或先停任务；书立即隐藏，后台停止生成并永久清理，清理暂未完成会静默自动重试。
- 多份最终输出一次导入，每份成为一本独立小说、一个独立工作区；同批按文件名自然排序，新批追加在已有书后。
- 导入或打开书库时，将书库顺序同步到 Harness 原生侧栏；「整理顺序」支持拖动、上移／下移和「恢复导入顺序」，每次调整立即保存。
- 书库固定编号 001、002……，卡片与导出书包一致；重复导入同一本书保留原编号；删除不会使其他书重排，旧号不分配给其他书，新书继续末尾编号；筛选或部分导出也不重新编号。
- 单本续写 10／20／50 章，或一直写至全本。
- 在书库先勾选，再让所选书各新增 10／20／50 章或写至完本；可明确切换到全部可新增的书。
- 暂停／继续只影响所选书，其他书照常生成；新书可加入运行中的队列，已有任务继续原目标。
- 原版系统提示词、单章与修订模板；每章带完整文风及前 10 章正文全文。
- 每章正文保存后，独立模型会话使用作者的标题提示词，只读本章；先看前 800 字抓钩子，再看前 2000 字，拟 5 个 15—25 字候选并推荐前三。
- 每章 TXT 开头按 1—5 编号列出全部已保存的候选标题，供发布时自行选择，随后是原书名、章号和正文。文件名沿用第一推荐，策略和番茄标签仅存内部记录。旧记录只有一个标题时导出该标题，不额外调用模型；标题失败只重试标题，升级不改写已有正文或标题。
- 每章新建原生会话，正文与状态分开保存，进度可暂停、恢复和核对。
- 模型和多个中转站统一使用 Harness 原生设置；单书与书库可为新批次选择「写作模型」及该模型支持的「思考强度」，默认带入当前会话配置，可改选，按界面显示值启动并保存。
- 启动时保存本批模型与强度，正文和独立标题均使用该选择；恢复沿用原批设置，运行中追加的新书可选择其他模型，主会话设置不变。

安装包仅包含长篇功能，不包含剧本、游戏、视频工作台或 Oh Story 写作技能。官方宿主、模型凭据、权限和会话继续由 Harness 管理。

请先安装 [官方 DeepSeek Harness](https://deepseek.com/harness/)。已验证的宿主基线为 `0.2.2-rc.3`。下载本派生版本的预构建 `.tgz` 后，在「插件 → 添加插件」使用安装包路径或发布页提供的直链；也可执行：

```sh
dsh plugin --profile desktop add /完整路径/oh-story-dsh-0.1.26-serial.10.tgz
```

更新同一插件会保留书库、其他插件和模型设置；保存工作后重新打开 Harness，确认工作台顶部运行版本为 `0.1.26-serial.10`。

这份源码根目录是开发用 monorepo，不能作为可安装插件根。不要使用上游 npm 同名包代替本长篇版本。

## 开始使用

1. 在 Harness 新建一个空文件夹工作区，作为「小说书库」。
2. 打开长篇工作台，批量选择一个或多个最终输出 TXT／Markdown 文件。每份文件创建独立小说目录，并登记为原生工作区。
3. 在「设置 → 模型」添加中转站的基础地址、协议、密钥、准确模型 ID；在工作台「写作模型」选择本批要用的已配置模型；默认已带入当前会话配置，按界面显示值启动；「思考强度」只显示该模型支持的选项，新增配置后可点「刷新模型列表」；要重新带入原生会话最新选择，先刷新列表，再选「使用当前会话配置」。
4. 在书库勾选需要更新的书，选择每本新增 10／20／50 章或写至完本；也可打开单书生成。操作前会显示本次书籍范围与数量；模型与强度在本批启动时一并保存。
5. 进度逐章保存。勾选后可暂停或继续这些书，继续会沿用原批目标、模型和思考强度，不额外加章。全局恢复不会自动恢复单独暂停的书。共享账号／网络问题先处理，再继续；Harness 退出后重新打开原书库并明确恢复。

书库使用整页列表，选书、生成、导出与删除集中操作，不在书单里另套滚动区域。运行记录放在折叠的「查看运行记录」中，只供查看；正文、大纲及设定仍在单书项目预览和编辑。标题阶段暂停时会明确显示标题已暂停，继续只补标题。「整理顺序」会显示全部未删除书，清空搜索并暂停搜索，点「完成整理」退出；调整位置不会改变固定书号或书包编号。旧书库按此前显示顺序建立初始编号，首次导入、导出或删除等操作时固定保存；不推断无法恢复的原导入时间，不改原书名、目录或正文。

已完成章节的预览显示「公众号备选标题」，可直接查看对应候选；原正文里的短章名保留。旧章只有短章名或单个旧标题时沿用已有内容，新版续写的新标题必须有五个 15—25 字候选；旧调用返回单个标题时只重试标题。

运行时保持 Harness 常驻和电脑唤醒。密钥由各自电脑的 Harness 保存，安装包不含模型账号。详细使用说明、验证证据和源码位于同次交付的合伙人安装 ZIP。模拟流程测试不等于真实中转账户或文学质量验收。

派生自 [zenstory-ai/oh-story-dsh](https://github.com/zenstory-ai/oh-story-dsh) `0.1.26`（MIT），复用其原生插件接入和文件工作台基础，非上游官方发行。原生成器提示词和状态约定来自用户提供的源程序；许可证及来源说明随安装包提供。

书间并发默认「同时生成（不限并发）」，也可填写任意正整数，不设固定并发上限；同一本书仍逐章生成。正文验收只要求超过1500字，不设字数上限。首次失败后自动重试5次，再失败才提示处理。
