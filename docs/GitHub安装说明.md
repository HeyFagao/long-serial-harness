# 从 GitHub 安装插件

仓库：[long-serial-harness](https://github.com/HeyFagao/long-serial-harness)（公开，无需 GitHub 登录）。

1. 安装并打开 [官方 DeepSeek Harness](https://deepseek.com/harness/)。已验证宿主版本为 **0.2.2-rc.3**。
2. 打开「插件 → 添加插件 → 包名或地址」，粘贴下面的插件安装直链并安装：

```text
https://github.com/HeyFagao/long-serial-harness/releases/download/v0.1.26-serial.10/oh-story-dsh-0.1.26-serial.10.tgz
```

3. 保存当前工作后重新打开 Harness。在「设置 → 模型」添加自己的中转站地址、密钥和模型；回到工作台选择本批「写作模型」与该模型支持的「思考强度」，默认带入当前会话配置，可改选，按界面显示值启动并保存。
4. 添加一个空文件夹工作区作为小说书库，打开长篇工作台，批量导入最终输出 TXT／Markdown。

一个文件建立一本小说、一个独立项目。单本可生成 10／20／50 章或全本；书库先勾选再让所选书各新增 10／20／50 章或写至完本，也可明确选择全部可新增的书。先试写 1 章检查线路与文风。

若直链安装受网络影响，可从 [发布页](https://github.com/HeyFagao/long-serial-harness/releases/tag/v0.1.26-serial.10) 下载 `long-serial-partner-0.1.26-serial.10.zip`，解压后运行包内 Mac／Windows 安装脚本；也可在插件安装器填写本地 `.tgz` 的完整路径。

安装器需要上述 `.tgz` 链接或文件，不要填源码仓库地址或 GitHub 的 Source code ZIP。

已安装旧版本的用户：用上面的 serial.10 直链重新添加/更新同一插件，保留书库、其他插件与模型设置。安装后保存工作并重新打开 Harness，再确认工作台顶部显示运行版本 `0.1.26-serial.10`；旧版本不会因为仓库更新而自动替换，已运行的旧进程也需要重开才能加载新版。

删除方式保持不变：勾选后点「删除所选书」立即移除，不再确认移入回收站。后台自动停止选中书的生成并永久清理文件，不会因为暂时清理失败把书重新显示出来。需要留稿时先导出。

serial.10 修复 Harness 侧栏中新工作区自动置顶导致的混排：升级后重新打开原书库，侧栏会与书库顺序同步。需要自行排列时，点击「整理顺序」，拖动书卡或使用「上移」「下移」；每次调整立即保存，点「完成整理」退出。「恢复导入顺序」回到原导入排列，固定书号与导出书包编号都不变。

继续保留书库固定编号：同批按文件名自然排序，新批接在已有书后，卡片编号与导出书包前缀一致。重复导入同一本书保留原编号；删除不会使其他书重排，旧号不分配给其他书，新书继续末尾编号；只导出部分书也不重新编号。旧书库按此前显示顺序建立初始编号，首次导入、导出或删除等操作时固定保存，保留原书名、目录和正文。

继续提供单书与书库的「写作模型」「思考强度」及「刷新模型列表」。列表来自 Harness 已配置模型；本批启动后保存设置，正文、独立标题和恢复均使用原批选择，追加新书可以选其他模型，主会话设置不变。五个已保存的候选标题仍全部编号放入每章 TXT 开头，发布时自行选择；文件名继续沿用第一推荐。旧记录只有一个标题时导出该标题，不额外调用模型，升级不会重做已保存的标题或正文。继续支持所选书暂停／继续、运行中添加新书和整页选书操作，独立标题调用沿用作者提供的提示词。

生成新章后，打开该章预览，在「公众号备选标题」中查看对应的候选；正文首行仍可保留原章名。旧章仅有短章名且没有独立标题记录时，导出会保留原章名；升级不会自动为旧章付费补题。
