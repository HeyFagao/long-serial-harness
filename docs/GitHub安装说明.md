# 从 GitHub 获取插件

仓库：https://github.com/HeyFagao/long-serial-harness

发布页：https://github.com/HeyFagao/long-serial-harness/releases/tag/v0.1.26-serial.3

仓库设为私有，包含这套原版写作提示词。拥有访问权限的人登录 GitHub 后，从发布页下载 `long-serial-partner-0.1.26-serial.3.zip` 并解压；也可让仓库持有者直接转发本 ZIP。

先安装官方 DeepSeek Harness，再运行包内 Mac／Windows 安装脚本。或在「插件 → 添加插件 → 包名或地址」填写解压后的 `oh-story-dsh-0.1.26-serial.3.tgz` 完整路径。

私有附件网址不能作为免登录安装直链；不要把源码仓库地址或 GitHub 的 Source code ZIP 直接填入插件安装器。
