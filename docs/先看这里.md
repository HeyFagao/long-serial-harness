# 长篇连载工作台

`0.1.26-serial.8`，安装到官方 **DeepSeek Harness 0.2.2-rc.3** 内。它沿用原长篇生成器的绿色双列界面和原版提示词，导入已经完成的设定、文风与章纲，连续生成正文。升级后保存工作并重新打开 Harness，确认工作台顶部运行版本为 `0.1.26-serial.8`。

## 开始使用

1. 安装官方 Harness，在「插件 → 添加插件 → 包名或地址」粘贴 [插件安装直链](https://github.com/HeyFagao/long-serial-harness/releases/download/v0.1.26-serial.8/oh-story-dsh-0.1.26-serial.8.tgz)；完整步骤见 [GitHub 安装说明](GitHub安装说明.md)。也可解压本包运行 Mac／Windows 安装脚本。
2. 在 Harness「设置 → 模型」添加自己的中转站和模型；回到工作台的「写作模型」选择本批模型；默认带入当前会话配置，可改选，按界面显示值启动并保存。「思考强度」只提供所选模型支持的选项；新增配置后点「刷新模型列表」。换线路无需改代码，见 [中转站设置](中转站设置.md)。
3. 打开书库文件夹，批量选择最终输出 TXT／Markdown。一份文件建立一本书的独立目录与原生工作区。
4. 先试写 1 章，检查后选择单书 **10／20／50 章／全本**；也可以在书库先勾选，再让所选书各自 **新增 10／20／50 章／写至完本**。需要全库操作时切换「全部可新增的书」；默认同时生成，也可自定并发数。

每章新建独立原生会话，自动带入完整文风及前 10 章正文全文。模型返回正文和状态变更，由宿主检查、保存、记账；无需另装 Python。正文完成后另起独立标题会话，按作者提供的提示词从本章前 800／2000 字提取钩子，拟 5 个 15—25 字候选并推荐前三；本章其余正文仅用于核实事实。导出为每章TXT、每本书ZIP，每章 TXT 开头列出全部五个候选标题供发布时选择，随后保留书名、章号和正文；旧记录只有一个标题时导出已有标题，不额外调用模型。书库支持勾选导出或直接删除；删除后立即从列表消失，后台停止选中书的任务并永久清理目录，暂时未清理完也不会重新显示。支持暂停、停止和恢复同一批，首次失败后自动重试 5 次，失败后等待处理。

勾选后可「暂停所选书」「继续所选书」，其他书继续运行；已有批次继续原目标、模型和思考强度，未开始的新书可以加入当前队列，并选择另一模型；主会话和已有书的模型设置不变。全局继续不会恢复单独暂停的书。运行记录折叠为只读，日常操作无需修改它们。

运行时保持 Harness 常驻、电脑唤醒、网络可用。关闭页面可以继续；退出宿主后重新打开原项目并恢复。
