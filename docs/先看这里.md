# 长篇连载工作台

`0.1.26-serial.4`，安装到官方 **DeepSeek Harness 0.2.2-rc.3** 内。它沿用原长篇生成器的绿色双列界面和原版提示词，导入已经完成的设定、文风与章纲，连续生成正文。

## 开始使用

1. 安装官方 Harness，在「插件 → 添加插件 → 包名或地址」粘贴 [插件安装直链](https://github.com/HeyFagao/long-serial-harness/releases/download/v0.1.26-serial.4/oh-story-dsh-0.1.26-serial.4.tgz)；完整步骤见 [GitHub 安装说明](GitHub安装说明.md)。也可解压本包运行 Mac／Windows 安装脚本。
2. 在 Harness「设置 → 模型」添加自己的中转站，选定写作模型。换线路无需改代码，见 [中转站设置](中转站设置.md)。
3. 打开书库文件夹，批量选择最终输出 TXT／Markdown。一份文件建立一本书的独立目录与原生工作区。
4. 先试写 1 章，检查后选择单书 **10／20／50 章／全本**；也可以让书库所有项目依次 **新增 10 章／新增 20 章／写至完本**。

每章新建独立原生会话，自动带入完整文风及前 10 章正文全文。模型返回正文和状态变更，由宿主检查、保存、记账；无需另装 Python。正文完成后另起独立标题会话，仅根据本章起一个公众号长标题。导出为每章TXT、每本书ZIP，书库支持勾选导出与移入回收站。支持暂停、停止和恢复同一批，首次失败后自动重试 5 次，失败后等待处理。

运行时保持 Harness 常驻、电脑唤醒、网络可用。关闭页面可以继续；退出宿主后重新打开原项目并恢复。
