## 本版检查

| 内容 | 结果 |
| --- | --- |
| 源码检查 | lint、类型、构建通过；30 个测试文件、343 项测试通过。 |
| 模型目录 | 读取 Harness 原生已配置提供商、模型和对应思考档位，目录不返回密钥、地址或配置；非文本模型不供写作选择。 |
| 独立选择 | 实际单书界面选择不同于主会话的模型与低强度，正文和独立标题都使用所选路由，主会话选择保留。 |
| 书库批量 | 实际书库界面选择模型与高强度，后续追加另一模型与低强度；每本书保存自己的批次快照。 |
| 请求核对 | 3 本书、4 章正文及4份通过验收的独立标题（含一次标题格式失败重试），核对模型请求实际发送的 model、output_config.effort，以及宿主持久化 provider/model/reasoningEffort 请求头。 |
| 冷恢复 | 暂停后改主会话模型与强度，再重启宿主恢复；运行过的书及待生成书都继续使用各自保存的设置。 |
| 无效设置 | 不支持的强度在模型请求和任务写入之前拒绝；模型移除、跨模型旧强度和不合法字段有单元回归，不静默切换线路。 |
| 强度默认 | 原生适配器的有效默认值在批次开始时保存；无默认强度时明确清除子会话对父会话显式强度的继承。 |
| 界面一致 | 新批次发送界面已显示的有效模型与强度；换模型清除旧强度；继续原批次不使用新选项。 |
| 原有功能 | 原正文提示词、独立五候选标题、标题TXT导出、选书暂停继续与删除相关单元回归通过。 |

本版原生模型矩阵使用官方目录中的 DeepSeek Flash／Pro 两个模型及其原生档位，地址指向本地测试模型。GPT、Claude、Gemini 等配置目录和适配器自有强度 ID 有单元检查；实际付费线路未逐一调用。协议参数由 Harness 原生适配器处理，插件不拼接自制协议参数。
