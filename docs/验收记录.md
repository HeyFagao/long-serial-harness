| 旧库升级 | 10 本旧书没有序号账本时，读取沿用之前按书名排列的顺序，不写文件；首次导入前保存该完整映射，再分配新号。不能恢复没有记录的历史导入时间。 |

| 删除与追加 | 删除002不改变其他书编号，下一本新书为014；删掉最高014后，另一新书得到015，不把014分配给其他书。 |
| 重复导入 | 同一本书保留原ID和序号；删除后重新导入完全相同内容及书名，仍为002，不改变后续分配位置。重新导入不恢复已删除正文。 |
| 重启与页面 | 冷重启后全部编号与顺序保持；书卡编号与导出编号一致，原勾选标签不变。搜索过滤不重编号。 |
| 并发与失败 | 序号文件CAS冲突不覆盖另一写入；损坏账本不静默重新编号；失败导入重试保留已分配身份。 |
| 删除兼容 | 首次删除前冻结旧库全部编号，含旧回收站及隐藏清理任务；无删除任务的后台检查不写账本。保留原来的立即隐藏和后台清理机制。 |
| 内容边界 | 旧项目记录、源稿原字节保留，书名、目录路径、正文不改；固定编号只记录在独立的书库顺序文件里。 |
