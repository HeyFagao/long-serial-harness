# 来源与源码说明

本地版本 `0.1.26-serial.10` 是运行在官方 DeepSeek Harness `0.2.2-rc.3` 内的长篇连载插件。它恢复用户原 ZIP 的长篇原型与提示词，接收已完成的设计、设定、文风和章纲，连续生成正文。日常使用见 [长篇连载说明](使用说明.md)，模型接入见 [中转站说明](中转站设置.md)，证据范围见 [验收记录](验收记录.md)。

## 本版边界

- 单书界面沿用原绿色长篇原型。书库改为整页选书与批量操作，不在书单内嵌套滚动区域；技术运行记录折叠且只读，正文、大纲和设定仍可编辑。
- 保留原系统提示词、首轮及修订提示；修复上下文漏传，每章和修订均带入完整文风与此前最多 10 章正文全文。
- 使用官方 `subagents.startActivation` 创建全新章节子会话，使用该批保存的模型与思考强度并继承宿主权限。调度不额外调用父模型；模型返回正文和状态变更，由宿主分离、检查并持久保存。模型不负责操作书文件或执行记账命令。
- 使用 Harness 原生已配置模型目录，单书与书库启动前可选择提供商／模型及该模型声明支持的思考强度；默认带入当前会话配置，可改选，按界面显示值启动并保存。选择只作用于新批，正文与独立标题一致；恢复沿用原批设置，运行中新增书可另选模型，不修改主会话模型或凭据。
- 单书支持 10／20／50 章或大纲全本，提供单章试写；默认 2300—2500 字为可配置参考目标。正文超过 1500 字即可通过字数验收，不设上限，原提示词与文风保持原文。
- 导入或打开书库时，使用 Harness 原生工作区排序同步书库顺序到侧栏；支持拖动、上移／下移和恢复导入顺序，调整立即保存；显示位置改变不重分书号或导出编号。
- 每个书库存储持久顺序和固定编号：同批按文件名自然排序，新批追加在后，重复导入同一本书保留原编号；删除不会使其他书重排，旧号不分配给其他书，新书继续末尾编号；筛选和部分导出不重新编号。旧库按此前显示顺序建立初始编号，首次导入、导出或删除等操作时固定保存，不追溯无法确认的原导入时间，不改书名、路径或原稿。
- 多份最终输出分别导入独立书目录与 Harness 工作区。七区成品保留原文、拆分章纲，并识别核心设定中内嵌的完整文风。
- 书库队列默认只操作勾选书，可新增 10／20／50 章或写至完本，也可明确选择全部可新增的书。书间默认同时生成，可设置任意正整数并发数；运行中可加入新书。所选书可单独暂停／继续，继续保留原目标，全局继续保留单独暂停状态。单书失败不影响其他书继续；共享接口错误在重试耗尽后暂停书库并停止其他在途任务。
- 正文保存后额外用全新的原生会话执行作者的章节标题提示词，只读本章正文，不影响写作提示词和前文。优先看本章前 800／2000 字，拟五个 15—25 字候选和前三推荐；其余本章正文用于核实事实。五个候选全部编号放在每章 TXT 开头，供作者选择；文件名沿用第一推荐，随后保留原书名、章号与正文。简短策略和标签只存独立标题记录。旧记录只有一个标题时导出该标题，导出不额外调用模型，也不会因升级自动重做旧标题。
- 勾选书后直接永久删除，界面立即隐藏，后台停止选中书的正文或标题调用、移除队列记录，再清理项目目录。清理暂时失败会静默重试，重新打开书库后继续；不会恢复显示。旧回收站仅保留导出和永久删除入口。
- 正文检查失败时先备份，首次失败后自动重试 5 次。用尽后等待作者明确重试；显式重试只追加当前章的有界尝试窗口，累计次数、任务身份和备份不清零。
- 停止后可以恢复同一批，保留未验收稿并继续核验或修订。已验收章节的哈希复查发现变化即停批保留现场，不提供文件系统级写保护，也不自动回滚作者编辑。

## 源码构建与验证

准备 Node.js `24.9+`、pnpm `11.7.0`，在源码根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm verify
pnpm pack:local
```

包内 `纯小说源码_0.1.26-serial.10.zip` 解压后按上述命令操作，生成包写入源码的 `release/`。将 `.tgz` 与安装脚本放在同一交付目录。日常使用官方桌面版内置运行时，无需为了生成小说安装 Python，也不依赖模型工具调用。

精简交付源码的 `pnpm verify` 包含 lint、类型、单元测试和构建；最终包另做绑定包哈希的原生流程、并发、批量导出和永久删除验证。本版结果见 [验收记录](验收记录.md)。四类协议独立验证收据来自 serial.3，属于历史验证。真实付费模型与文学质量单独记录，不能用模拟结果替代。
