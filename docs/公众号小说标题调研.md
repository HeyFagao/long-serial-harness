# 公众号小说长标题：调研与接入方案

调研核查日期：2026-11-17。serial.6 按作者新提供的提示词更新接入规则，目标仍是每章一个适合独立推文的标题，保留本章事实，不干扰小说正文生成。下列材料有编辑访谈、行业调查和研究论文；不是当前小说付费转化排行榜，也没有把历史账号阅读量当成本项目的效果承诺。

## 查到了什么，如何采用

| 来源 | 可用发现 | 本项目如何采用 | 证据边界 |
| --- | --- | --- | --- |
| [新榜编辑方法总结，2016](https://www.newrank.cn/article/detail/2729) | 强调受众相关性、易理解、从事件矛盾提取故事看点。 | 把陌生人名转成正文支持的关系称谓，先让陌生读者知道谁与谁发生冲突。 | 编辑经验，年代较早，不是小说标题的随机实验。 |
| [新榜采访标题编辑，2017](https://www.sohu.com/a/127544125_108964) | 同一篇先拟多个候选，比较好奇心与戏剧冲突，避免自我重复。 | 独立标题调用拟五个候选和前三推荐，自动取第一推荐；候选仅存内部记录。 | 访谈反映特定团队实践，账号成功不能单独归因于标题。 |
| [新榜两千余篇历史高阅读标题观察，2017](https://www.newrank.cn/article/detail/3316) | 长短标题都存在，较长标题能够承载事件与画面。 | 旧版曾建议 25—45 字；serial.6 改为作者要求的 15—25 字，围绕一个冲突，不截断凑长度。 | 只观察成功样本，有选择偏差；不能推出越长越好，也不据此宣称当前平台长度限制。 |
| [Shulman 等，Science Advances，2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11152133/) | 三万余次新闻标题实验及后续实验支持常用词、易理解表达。 | 长标题也用简单句和具体动作，避免难词、名词堆叠、绕口修辞。 | 英语新闻为主，迁移到中文小说是本项目设计推断；简单不等于一味缩短。 |
| [Qiu 与 Golman，Applied Cognitive Psychology，2024](https://doi.org/10.1002/acp.4195) | 分析十万余篇微信新闻，研究信息缺口、显著问题与阅读选择；好奇点击不等于长期参与。 | 明确一个读者想追问的问题，同时让正文兑现它；不把关键情境全部藏掉。 | 微信新闻的研究，不是小说商业收益试验。 |

作者提示词中的“百万在读”等措辞作为创作目标保留，不是程序对传播效果的承诺。调研材料里“某种标题保证十万加”“标题占成功的固定百分比”等说法也没有作为验证结论。搜索到的旧营销文章中的新闻化、夸大化说法也不直接搬进小说标题。用户要求的事实边界是：只根据这一章已经写出来的内容。

## 转为小说时的具体方法

核心结构是“关系或身份＋具体冲突/行动＋有方向的悬念”。它是本项目根据上述证据作的编辑设计，不是论文给出的万能公式。六种角度按题材挑选，不能每章套同一个模板：

| 角度 | 适用材料 | 标题要保留的吸引力 |
| --- | --- | --- |
| 关系冲突 | 亲属、伴侣、师徒、同事之间的明确行动 | 谁越过了谁的边界，主角作何反应 |
| 利益得失 | 已出现的合同、钱款、房产、资源、机会 | 可感知的代价，而非抽象“很惨” |
| 身份反差 | 本章已给出的身份与行为不协调 | 反常行动的原因，不抢先泄露未揭晓身份 |
| 物证揭示 | 信件、钥匙、签名、录音等本章真实物件 | 物件为何改变判断，少用“那个东西” |
| 反常行动 | 人物做了与预期不同的决定 | 让读者想问为什么，不用空洞惊叹 |
| 两难选择 | 两个选择都带明确损失 | 让读者想知道主角如何选择 |

原创示意，仅说明结构，不是用户小说的既有剧情：

- 假设本章写明：家人催女主签字，女主发现收款人写着自己的名字。可拟“家人催我签字，收款人竟写着我的名字”。它交代人物关系、动作和异常；读者想知道这份协议的真实目的。
- 假设本章写明：师父烧掉名册，少年从灰中认出自己的旧姓。可拟“师父烧尽弟子名册，灰里却藏着我的旧姓”。只有正文第一人称时才可用“我”；否则改写为第三人称。
- “命运的转折”“他终于明白了”“惊天秘密震惊所有人”没有给读者具体问题，不作为默认成品。

## 独立调用边界

正文会话继续执行原写作提示词，含完整文风和此前十章正文。正文通过验收并保存后，另起一个全新原生会话，继承同一主会话的中转站和模型，只发送书名、章号、本章完整正文和专用标题提示词。

标题会话不能调用文件工具，不接收全书大纲、其他章正文或正文写作会话历史。按作者提示词，优先看本章前 800 字，再看前 2000 字，其他本章正文用于核实事实。它输出五个 15—25 字候选、前三推荐、简短核心爆点、标题策略、番茄标签，以及一至五段本章原文依据；系统自动取第一推荐。宿主检查依据确实是本章中的连续原文，再把结果与正文哈希、章号、独立会话身份一起保存。这个检查证明引用存在；标题与证据之间的语义关联仍由模型自检和作者审阅，不能称为程序已经证明标题质量。

标题首轮失败后最多自动重试五次，只重试标题。正文文件与写作回执保留；暂停、停止、重启恢复覆盖标题阶段。标题完成后才推进下一章。通常每章至少两次模型调用：正文一次、标题一次；修订或失败重试会额外产生调用与费用。

候选、策略、标签与依据只存标题记录，不进入正文或 TXT。TXT 第一行是选定标题，随后保留原书名、章号和正文。更新不会自动重做已有标题或正文。

导出不调用模型。新章使用已保存的公众号标题；旧章没有独立标题记录时保留原章节名，并在目录说明中标识，不静默编一个“吸引人标题”。正在补标题的当前章暂不进入导出，先前已完成章仍可导出。

提示词全文见 [公众号小说标题提示词](公众号小说标题提示词.md)。要评估真实效果，应在自己的公众号观察打开率、后续阅读和反馈，不能用模型自评分替代真实读者行为。
