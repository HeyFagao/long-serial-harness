# 长篇连载插件源码

版本 `0.1.26-serial.9`。这是从长篇连载工作台代码裁剪出的开发源码快照，保留原版系统提示词、多书导入、逐章生成、上下文关联、状态与书库队列。它不包含旧剧本、游戏、视频工作台或四套知识资产，也没有模型密钥、用户小说或本机设置。

最初的小说专用源码由构建入口的 TypeScript 依赖闭包选择；serial.6 在该基线上加入所选书批量生成、单独暂停／继续、运行中添加新书，调整书库布局与只读运行记录，并接入作者提供的独立章节标题提示词。serial.7 将已保存的五个候选标题全部编号放入每章 TXT 开头，供发布时选择，导出不额外调用模型。serial.8 使用 Harness 原生模型目录，在单书与书库提供批次模型、思考强度选择；启动时保存该选择，原批恢复及已运行书保持原设置，新加入书可单独使用另一模型。serial.9 为每个书库持久保存书籍顺序与固定编号，同批按文件名自然排序，新批接在末尾，卡片与书包编号一致；旧号不分配给其他书。标题与正文调用分离，保留原正文生成提示词文件；继续提供直接删除所选书、后台停止任务与静默重试清理。`SOURCE_DISTRIBUTION.json` 记录保留文件哈希及排除测试的原因。本快照用于构建和审查，并不自动意味着真实模型写作验收通过。安装者请使用同次交付的预构建安装包与最终使用说明。

## 开发

需要 Node.js 24 及 pnpm 11.7.0。

```sh
pnpm install --frozen-lockfile
pnpm verify
pnpm pack:local
```

`verify` 运行代码检查、类型检查、保留单元测试与构建。`pnpm test:dsh:library` 是使用真实 Harness、浏览器及本地确定性模型的多书集成测试；需先设置 `SERIAL_PLUGIN_TARBALL` 为本次冻结安装包绝对路径，并提供 Playwright Chromium 与可用的 Harness 测试安装。测试默认离线安装宿主，开发者应预先缓存依赖或通过 `DSH_SMOKE_INSTALLATION` 指向测试安装，测试运行不使用付费模型。

此源码快照没有 GitHub 自动发布工作流，包标记为 private，不向上游 npm 发布。根目录是开发 monorepo，不是供 Harness 直接安装的插件根。
